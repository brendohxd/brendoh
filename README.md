# brendoh

The personal home of Brendon: a small, bright index of projects, research, notes, and experiments taking shape in public.

## Run locally

```bash
npm install
npm run dev
```

The site is built with the OpenAI Sites starter, Next-compatible React, and Vinext. The primary experience lives in `app/page.tsx`; visual tokens and responsive layout live in `app/globals.css`.
